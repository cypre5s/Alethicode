# Admin AI 隐藏入口设计

**目标**

从 Admin 管理端移除 `McMining 审核` 与 `预检帮助率` 两个入口，并同步禁止对应前端路由的直接访问。

**现状**

- 两个入口当前在 Admin 侧边栏中对 `Super Admin` 可见。
- 两个页面当前都注册在 Admin 前端路由表中，因此即使菜单隐藏，仍可通过手输 URL 进入。

**方案**

- 从 `SideMenu.vue` 删除两个菜单项。
- 从 `admin/router.js` 删除 `/mcmining-review` 与 `/preflight-stats` 两个子路由。
- 同步清理前端测试路由登记，避免 E2E 配置继续把这两个页面视为有效页面。

**链路检查**

- 输入：管理员打开 Admin 管理台，或手动访问旧 URL。
- 处理：侧边栏不再渲染两个入口；路由表中不存在两个页面。
- 输出：菜单中看不到入口；手输旧地址时不会进入对应页面。
- 上下游影响：不修改后端接口，不删除页面源码文件，仅收缩前端暴露面。

**未验证前提**

- 旧地址失效后回退路径沿用当前 Admin 路由的默认行为。
