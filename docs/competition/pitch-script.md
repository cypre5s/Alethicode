## 第四幕 · 把这个"老师"拆开给你看

（屏幕分屏四块）

我们要的不是噱头。

我们要的是**能回答 A 同学"哪里错了"**的 4 件事。

### 1. 真实的判题

Python、C、C++、Java 四门语言的真实代码执行。

容器沙箱、资源限制、时间限制、内存限制——和 ACM 竞赛机房一样严格。

但不是所有学生都要成为 ACM 选手。

### 2. 真实的诊断

7 个阶段的状态机：审题 → 构思 → 编码 → 错因诊断 → AC 复盘 → 迁移练习。

每一步，由一个**专门的 AI Agent** 接手。

错因不是"有一个错"三个字——

错因是：

> **"你在 `input()` 那一步漏了 `float()`，所以 `radius * radius` 退化成了字符串拼接。像你这种错误，过去一个月我看到过 47 次。我给你一条台阶，试试看。"**

（停顿，看观众）

这句话，**不是** GPT 背出来的。

这句话，是我们为这件事，**训练了 7 个专用的小模型**。

### 3. 真实的记忆

LangGraph 的 Checkpoint，让会话能从断点恢复。

学生刷新页面、断网、关机——重新登录的那一刻，AI 记得他说过的每一句话，记得他错过的每一道题。

"老师，我不敢再说一遍我哪里错了。"

"没关系，我记得。"

### 4. 真实的学情

每一个班，每一个学生，每一个知识点，每一天的掌握热力图。

老师不必再一个个翻学生代码。

早上 9 点，她打开 Alethicode，系统告诉她：

> **"今天这个班，有 73% 的学生，在 `range(n)` 的边界上翻车了。请重讲。"**

她重讲。

那一天，这 60 个孩子**真的学会了**。

## 第五幕 · 我们到底建了什么（给工程同仁看的一张图）

（屏幕切换：系统架构图）

（加快语速，数据快剪）

- **后端**：986 个 Java 源文件，150+ REST 端点，59 次数据库迁移。Spring Boot + PostgreSQL + pgvector + Redis。
- **前端**：245 个 Vue 组件，3,300+ 个 JS/TS 模块。Vue 3 + Vite + Element Plus。
- **AI 引擎**：独立的 Python 服务 `tutor-graph`，基于 LangGraph，Postgres 做 Checkpoint 持久化。
- **模型**：**7 个自研小模型**——Alethi-CodeBERT-Edu、DiagGNN、Transfer-Reco、LearnerEmb、CodeQA-Scorer、KC-Tagger、Interrupt-Policy。
- **训练**：4×A800 GPU，420 万条学生代码，220 万条迁移练习记录，187 万条错因序列。
- **部署**：docker-compose / k8s / Helm 三套方案同步维护。
- **观测**：Prometheus 抓 300+ 指标，Grafana 面板 10+ 张，OpenTelemetry 全链路 trace。
- **韧性**：Circuit Breaker + Retry + Bulkhead + TimeLimiter + 多 Provider Failover（DeepSeek ↔ 通义 ↔ 火山 ↔ 智谱 ↔ MiniMax）。
- **合规**：ADR-0004 单独为"PIPL + 生成式 AI 管理办法 + 等保 2.0"立了一份架构决策。

（放慢，清晰）

这不是作业项目。

这是**一整套生产级、可部署、可审计的工程系统**。

## 附：演讲者备忘

- **节奏**：开场致意 30 秒 + 9 幕 + 尾声 + 终章 + 结语 ≈ 22 分钟；如时长吃紧可砍第七幕 SLO 表格到 30 秒，或把第五幕工程规模 bullet 合并念。
- **停顿**：标注 `（停顿）` 处坚持数 3 秒，信任沉默。
- **数据**：所有数字上屏**大号加粗**，讲的时候放慢。
- **情感弧线**：沉重（A 同学卡住）→ 升腾（政策 + 学校数字）→ 自豪（Alethicode 做了什么）→ 冷静（SLO + 合规）→ 共情（她 AC 那一刻）→ 愿景（明年她自己上台）→ **升华（育人为本、智能向善 + 总书记原话呼应）**。
- **手势**：数据段落掌心向上；A 同学故事段胸前手势；政策段指向屏幕；**终章"以人为本"段，手心向内按住胸口**。
- **最后两分钟的呼吸**：终章不能赶。`育人为本 · 素养为先 · 应用导向 · 智能向善` 每个词之间停 2 秒；`体验 · 教育 · 以人 · 为本` 每个词之间停 2 秒；让观众自己把答案接进去。
- **最后一鞠躬**：念完习近平原话"推进人工智能全学段教育和全社会通识教育，源源不断培养高素质人才"之后，**深鞠一躬 2 秒**，再退半步，让灯自然灭下去。
- **政策锚点的时间线**：第一幕按"2024 教育大会 → 2025.4.25 政治局第二十次集体学习 → 2026.4《"人工智能+教育"行动计划》"三点一线讲，不要乱序；记住总书记的那句"全学段、全社会、通识"是把政策和 1,200+ 非 CS 学生连起来的关键钩子。
- **东华元素三处锚点**：幕启"人文学院中文系"+ 课程名《计算思维与人工智能（Python 语言、C 语言）》；第二幕 12 个学院全称清单；第三幕"2025 年底信息与智能科学学院重组"；结语"崇德博学 · 砺志尚实"。这四处是让评委感到"这不是在讲一个泛泛产品，这是为东华量身定做"的关键抓手——**念的时候吐字要清晰**，尤其校训 8 个字每字间停 0.5 秒。
- **演讲人信息填写**：首页"演讲人"和"开场致意"两处 XXX 请在上台前替换为姓名 / 学院 / 年级；"汇报场合"替换为实际场合。
- **向评委席鞠躬**：开场一次、结语一次；中间戏剧段落（A 同学故事）不鞠躬，避免节奏被切断。
