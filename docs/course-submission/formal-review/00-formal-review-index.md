        ## 使用说明

        1. Markdown 中的图均采用 Mermaid，可在支持 Mermaid 的编辑器、Markdown 预览器或文档平台中渲染。
        2. 若需要 Word/PDF，建议先渲染 Mermaid 图为图片，再插入学院模板；当前生成的 Word 版会保留 Mermaid 源码块。
